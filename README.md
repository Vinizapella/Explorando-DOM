# 🌐 Explorando o DOM

> Manipulação do Document Object Model — tornando páginas web dinâmicas e interativas com JavaScript.

---

## 🗂️ Sobre

O projeto **Explorando o DOM** é um estudo prático sobre como o JavaScript interage com a estrutura HTML de uma página, permitindo criar, modificar, remover e estilizar elementos de forma dinâmica direto no navegador.

---

## 📖 Conteúdo abordado

- 🌳 O que é o DOM e como ele funciona
- 🔍 Seleção de elementos (`getElementById`, `querySelector`, `querySelectorAll`...)
- ✏️ Manipulação de conteúdo (`innerHTML`, `textContent`)
- 🎨 Alteração de estilos e classes dinamicamente
- ➕ Criação e remoção de elementos
- 🖱️ Eventos e listeners (`click`, `input`, `submit`...)

---

## 🚀 Como executar

```bash
# Clone o repositório
git clone https://github.com/Vinizapella/Explorando-DOM.git

# Acesse a pasta
cd Explorando-DOM
```

> Abra o arquivo `index.html` diretamente no navegador — sem necessidade de servidor! 🌐
